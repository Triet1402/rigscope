# Rigscope

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Linux machine owners and small-fleet operators who need to inspect their machines' resources and processes.

## Product Purpose

A self-hosted Linux system and process monitor. The public website helps visitors understand the software, explore a synthetic demonstration, and install it.

## Operating Context

A hub serves the dashboard; collectors connect outbound from monitored machines. The default installation runs both locally. Installation requires Linux, Node.js 26+ with npm, and systemd for background services.

## Capabilities and Constraints

CPU, memory, GPU, disk and network readings, history, process inspection, and alerts. Monitoring is read-only. GPU support depends on hardware and drivers. Each hub owns its users, permissions, and history. The website demo uses clearly labeled synthetic data and needs no live hub or credentials.

## Brand Commitments

Rigscope name, existing rack-frame mark, “Your machines, in view.” tagline, and current dark console identity. Installation is the website's primary action.

## Evidence on Hand

README.md and docs describe supported capabilities and installation. src/components contains the product UI. No testimonials or customer statistics are supplied.
